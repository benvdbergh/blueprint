This project is governed by the files in its GitHub repository. Before making changes:

1. Read `AGENTS.md` (shared rules for all agents) and `blueprint/00-product-core.md`.
2. For UI work, follow `blueprint/02-ux-design.md`: use the existing design tokens and components. Don't introduce new colours, spacing or one-off components unless the request asks for them.
3. Use the domain terms from the glossary in `blueprint/03-domain-data.md`.
4. When you add or change tables, columns or policies, also update the domain model in `blueprint/03-domain-data.md`, or tell me it needs updating.
5. Never edit `blueprint/00-product-core.md` or blueprint files with `status: approved`. Tell me what should change instead.

When a request conflicts with the blueprint, say so before implementing.
