# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue.

You can expect an acknowledgement within a week. Relevant areas include the installer (`bin/`, `cli/`), which writes files into a user's repository, and the GitHub Actions workflows the template installs, which run with repository permissions and can run AI agents.

## Supported versions

Only the latest released version of `product-blueprint` receives fixes.
