# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue.

You can expect an acknowledgement within a week. Relevant areas include the installer (`bin/`, `cli/`), which writes files into a user's repository, and the workflow instructions in `blueprint/workflows/`, which agents follow unattended, for example as scheduled tasks.

## Supported versions

Only the latest released version of `product-blueprint` receives fixes.
