# Prototypes

Approved UX prototypes that WF-02 compares the implementation against.

- **File name:** `FEAT-nnn-short-name.<ext>`. Use a static HTML export, PNG/PDF frames, or a `.md` file that links to an external prototype (Figma, Lovable preview, Claude artifact) plus a screenshot of the approved state.
- **Link it** from the feature spec front matter (`prototype:`) and from the screen inventory in `02-ux-design.md`.
- **Approval:** a prototype is approved when the feature spec it belongs to is `approved`. Changing it after that counts as changing an approved spec.
- **Outdated prototypes:** WF-07 flags prototypes that are older than the code they describe. Once a screen is implemented and its visual baseline exists, the baseline is the reference and the prototype can be archived.
